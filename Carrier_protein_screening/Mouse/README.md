## Mouse carrier protein process

#### Starting from Fastq file (SUB16415133). Running the scripts following the order below:
#### We extracted barcodes UMI and sequence and combined two sequencing batches using Mouse_CP_1.sh and Mouse_CP_2.sh. We draw rank plot and set thresholds using rankplot.m and thresholds1.sh, respectively. We filtered out the barcodes using barcode.sh. We used producedBCmat2.m to generate the maxrix and find_barcode_num_of_protein2.m to assign barcodes to each carrier protein. For general pipeline please also refer to (https//github.com/kebschulllab/MAPseq2-and-POINTseq/tree/main)
